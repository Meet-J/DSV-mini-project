# Expected values: how to confirm your Power BI model is right

Generated by `python -m src.powerbi_docs`. These numbers come from a pandas replica of the star schema and of every measure, and they agree with the independent SQL results in `output/sql_results.md` (`tests/test_powerbi.py` enforces this). **They are NOT produced by Power BI**: build the model, then add the measures to a table or card and compare. A mismatch means a build error (a relationship, a filter, a type), not a different truth.
