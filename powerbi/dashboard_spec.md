# Dashboard specification

Generated by `python -m src.powerbi_docs` from `src/powerbi_pages.py`; `tests/test_powerbi.py` checks that visuals stay on the canvas, never overlap, and only reference columns and measures that exist. Canvas: 16:9, 1280 x 720 px (Power BI default). Positions are x, y, width, height in px.

## Design rules (all pages)
- **Palette:** slate `#6B7F99`, dark slate `#3F5670`, grey-blue `#B8C2CF`, and one accent red `#C0504D` reserved for risk and above-average churn. Import `theme.json`.
- **Typography:** Segoe UI; page title 20 pt semibold, visual titles 12 pt semibold, KPI values 28 pt, labels 10 pt.
- **Axes:** every bar and column axis starts at 0. Percentages show one decimal (0.0%), counts use thousands separators, money has no currency symbol (the dataset does not state one).
- **Charts:** horizontal bars for category comparisons, columns for ordered bands. No pie or donut charts. Gridlines off, data labels on, no chart borders.
- **Colour use:** churn charts colour by `[Churn Bar Color]` (red only when more than 2 points above the overall rate); risk charts colour by `[Risk Color]`.
- **Language:** associations, never causes. Recommendations are hypotheses to validate.

## Conditional formatting recipes
- **Churn bars:** Format > Bars > Colors > fx > Format style: Field value > Based on field: `[Churn Bar Color]`.
- **Risk columns and the table's RiskCategory:** same steps with `[Risk Color]` (for the table, use Cell elements > Background colour).
- **ChurnProbability data bars:** Cell elements > Data bars > On, positive bar colour `#C0504D`.
- **Probability histogram:** Colors > fx > Format style: Rules, based on `FactCustomer[ProbabilityBinStart]`: below 0.30 = `#B8C2CF`, from 0.30 to below 0.70 = `#E8B4B0`, 0.70 and above = `#C0504D`.
- **Risk x value matrix:** Cell elements > Background colour > Gradient on `[Active Customers]`, minimum white, maximum `#C0504D`.
- **Reference line:** Analytics pane > Constant line > Value > fx > `[Overall Churn Rate]`; dashed, dark grey, label on.

## Drill-through (Customer Detail)
1. On page 5, drag `FactCustomer[CustomerID]` into Drill through > Add drill-through fields here; keep 'Keep all filters' off.
2. Page 5 > Page information > Hide the page (it is reached only by drill-through). Power BI adds a Back button automatically.
3. On page 3, right-click a row in the customer table > Drill through > Customer Detail.
