# Model training and selection report

Generated by `python -m src.train_model`. Every number below was computed by that run.

## 1. Setup
- Stratified split (seed 42): 5,634 training rows, 1,409 test rows; churn rate 26.54% in training, 26.54% in test.
- Tuning and selection: 5-fold stratified CV on the **training split only**, scored by ROC-AUC.
- All models use the feature set from `src/feature_engineering.py` (defaults). No class weights are used in the compared models (see section 4).
- The test split was first used after the model, hyperparameters and threshold were fixed.

**Selection rule (declared before running):** among models whose mean CV ROC-AUC is within one standard error (fold std / sqrt(folds)) of the best, choose the simplest, in the order Logistic Regression, Decision Tree, Random Forest, Gradient Boosting. Selecting the best CV mean after tuning is slightly optimistic for every model alike; the test set below provides the unbiased estimate.

**Outcome:** Best CV ROC-AUC: Gradient Boosting (0.8504, SE 0.0052). Models within one SE (>= 0.8452): Random Forest, Gradient Boosting. Simplest of those: Random Forest.

**How to read this against costs.** Contacting a customer with churn probability `p` is worth it when `p x s x V > c`, where `V` is the value of a retained customer, `s` the chance an intervention succeeds, and `c` the cost of the intervention. So the break-even threshold is `c / (s x V)`, which is valid only if probabilities are well calibrated (section 6). **The dataset contains no values for `c`, `s` or `V`**, so no business-optimal threshold is claimed here: a company supplies the ratio, and the table shows what each threshold implies for workload, precision and recall.

## 8. Caveats
- Single stratified split: the test set has about 374 churners, so metric differences between models of a few thousandths are not distinguishable (see the bootstrap interval).
- Hyperparameter search was small (grids or 15 random candidates) to keep the run reproducible on a single CPU.
- Figures are in `images/model/`; artefacts in `models/`.
